# 拾光复利 · 使用手册

> AI 个人经营系统：钱 · 时间 · 人。
> 核心玩法：**随口说一句话**，AI 自动识别出其中的日程、待办、收支、心情、饮食，分别记入对应模块；你在各模块里查看、修正、复盘。

- 线上地址：<https://shiguang.ting97.cn>
- 移动端浏览器已适配（触屏可直接看到操作按钮，无需悬停）

---

## 模块总览

| 模块 | 入口 | 一句话说明 |
|---|---|---|
| 🌱 动态 | 首页 `/` | 记录入口 + 动态流 + 待办 + 今日日程，日常操作都在这页 |
| 📅 日历 | `/calendar` | 日/周/月/年四种视图回顾时间去向，可补录修改日程 |
| 🕸 人际 | `/contacts` | 联系人档案、分组筛选、可拖动的人际图谱、往来时间线 |
| 💰 财务 | `/finance` | 月度收支总览、预算、账户、待确认流水、账单导入 |
| 🗂 分类 | `/categories` | 自定义活动分类（图标/颜色/默认时长） |
| 👤 个人设置 | `/profile` | 昵称、密码 |
| 🎫 邀请码 | `/invites` | 仅管理员：生成注册邀请码 |

导航栏在所有页面顶部，点击昵称可进入个人设置、退出登录。

## 一、动态（首页）

### 1.1 记录此刻

- 输入框里随口写一句（如「刚跑完步40分钟，心情不错」「明天下午三点看牙」「午饭吃了碗牛肉面」），点「发布」或按 **Enter**（Shift+Enter 换行）。
- **发布瞬间动态就上墙**（不用等 AI）；随后 AI 在后台对这句话做 **五个域的独立识别**，识别得出才记录，识别不出不强制，完成后识别产物自动出现在动态卡片上（卡片会先显示「🤖 AI 识别中…」）：

| 域 | 触发示例 | 产生什么 |
|---|---|---|
| 🕒 日程 | 「刚开完会1小时」「今天9:10到9:30工作准备」 | 今日时间轴上的时间块 |
| 📋 待办 | 「明天下午三点看牙」；**正在做的事**（如「今天9:10到9:30工作准备」在 9:20 记录）会额外生成一条**带起止时间的收尾待办** | 待办列表新条目 |
| 💰 收支 | 「打车花了32块」 | 财务页的**待确认流水** |
| 😊 心情 | 「有点累」 | 动态的心情标签 |
| 🍽 饮食 | 「午饭吃了碗牛肉面」 | 饮食记录 + 估算卡路里 |
| 👥 关系 | 「和老王吃了顿饭」 | 自动建档并记入 TA 的往来时间线 |

- AI 会结合当前时间判断事情**已发生 / 正在进行 / 还没发生**：已发生 → 日程时间轴；还没发生 → 待办；正在做（已开始未结束）→ 日程 + 一条带起始时间的收尾待办两样都记。
- 识别置信度低于 60% 的域**不会自动落库**，而是以「🤔 识别到 X（待确认）」出现在卡片上，你点「确认」才生效，点「忽略」则丢弃。
- 若识别出的日程时间与已有日程**冲突**，动态照常保存，但不会登记时间轴，卡片上会显示「⚠️ 未生成日程」及冲突原因。

### 1.2 我的动态（动态流）

- 按 **今天 / 昨天 / 历史日期** 分组展示，左侧时间线标注每条的记录时刻。
- **分页**：默认显示最近 10 条，底部「加载更多（还有 N 条）」每次多加载 10 条，加载完显示「已经到底啦」。
- **搜索**：右上角搜索框，输入停顿即自动检索（Esc 或 ✕ 清除）。搜索范围包括：动态原文、日程/待办标题、交易类别/对方/备注、联系人姓名、饮食条目。
- 每条动态可以逐项修正：
  - **心情**：点「改」换心情或清除；
  - **日程块**：改标题/起止时间/分类，或删除；
  - **待办**：改标题/时间/分类，或删除；
  - **金额**：改收支方向/金额/类别/对方，或删除；
  - **人物**：移除关联（不影响联系人档案）；
  - **删除整条**动态（识别产物一并删除）。
- **五域状态条**（卡片底部 🕒📋💰😊🍽）：✓ 已识别、· 未识别、? 待确认；**点图标可对该域单独重新识别**（适合 AI 漏识别或识别错时补跑）。

### 1.3 待办

- **完成**：点击待办行首的圆圈 → 标记完成（**日程与待办解耦**：完成不再自动生成时间块，时间轴只记你发布动态时识别出的日程）。
- **手动新增**：右上「＋ 新增」，只填标题、回车保存——**不需要填时间**（之后想补时间可再编辑）。
- **编辑**：✏️ 可改标题、开始时间、到期时间（均可清空）、分类；带起止时间的待办在列表里显示为「9:10–9:30」区间；🗑 删除。
- **今日已完成**：列表底部折叠区，支持 ↩️ 恢复为未完成（历史版本完成时生成过的日程块会一并撤销）、修改、删除。

### 1.4 今日日程

- **时间轴视图**：24 小时轴 + 彩色时间块，红线为当前时刻；顶部环形图显示今日各类时长占比；标题旁显示「🍽 今日 ≈N kcal」（饮食域汇总）。
- 点击**空白处**：自动定位到所点区域的整点，预填 1 小时日程方便补录（表单内可再调）。
- 点击**色块**：切换到列表视图并打开编辑器。
- **列表视图**：每条显示起止时间/图标/标题/时长，可「＋ 新增日程」、编辑、删除；结束时间必须晚于开始时间，冲突会提示。

### 1.5 提醒横幅

首页顶部自动出现：**即将过生日/纪念日的联系人**、**即将到期或已过期的待办**（接口异常时不打扰主流程）。

## 二、日历（`/calendar`）

四种视图，左上切换，均可前后翻页：

| 视图 | 内容 |
|---|---|
| 日 | 当日时间轴 + 环形图，点击空白补录整点日程、点击色块编辑 |
| 周 | 一周 7 列总览，逐日看时间块 |
| 月 | 每日记录时长环 + 月度汇总，未记录的日期灰色标识 |
| 年 | 全年热力图，颜色深浅代表记录多少 |

所有视图都能新增/编辑/删除日程（标题、起止时间、分类），保存时做冲突检测。

## 三、人际（`/contacts`）

### 3.1 列表与筛选

- **📋 列表 / 🕸 图谱** 双视图切换；搜索框按姓名/备注过滤。
- **分组筛选**：分组标签（朋友、家人…）点击加入/移出筛选，可多选。
- **新建联系人**：姓名、备注名、生日（阳历/农历）、纪念日、分组、重要程度、备注（可记喜好/忌讳/重要的事）。
- **生日支持农历**：切换到「农历」后选择月（正月~腊月）与日（初一~三十），可勾选「闰」表示闰月生日。
  生日提醒按农历自动换算成每年对应的公历日期（卡片上显示"N 天后生日"）；
  闰月生日在无闰月的年份按平月过，三十生日在小月按当月最后一天过。

### 3.2 人际图谱

- 你在中心，每个联系人按**重要程度五档**分布在对应轨道上：
  **5 亲密 · 4 重要 · 3 普通 · 2 一般 · 1 简单**（越重要离你越近）；重要程度在联系人档案里设置。
- **每个节点可用鼠标/手指拖动**摆位（微动不误触，拖出距离即生效）。
- 分组多选筛选同样作用于图谱。

### 3.3 联系人详情（点开某人）

- **档案**：生日（阳历/农历，农历会显示对应公历日期与倒计时）、纪念日、分组、备注（喜好/忌讳/重要的事）。
- **一起经历过的事**：时间线自动汇集动态里提到 TA 的记录，也可「＋ 补一笔往来」手动补记（类型 + 一句话）。
- **关联人情账**：财务流水里「对方」是 TA 的人情往来自动汇总，显示净额（送出为负、收到为正）。
- 支持「编辑档案」「删除联系人」。

## 四、财务（`/finance`）

- **月度总览**：本月收入/支出、支出环比上月、储蓄率；左右切换月份。
- **预算**：设置月度支出限额与提醒阈值，进度条按消耗程度变色警示。
- **分类占比**：本月支出按类别的构成条/图。
- **账户**：「管理」里新增账户（名称/图标/期初余额，如现金、招行储蓄卡、支付宝、微信），可归档（历史流水保留）；每笔入账流水可挂到账户，账户余额随之变动。
- **待确认流水**：动态里 AI 识别出的金额先以草稿存在这里——
  - 单笔「确认入账」：选择记入哪个账户或「不记账户」；
  - **⚡ 全部入账**：一键把本页所有待确认流水记入同一账户（或都不记）。
- **手动记一笔**：收支方向、金额、类别（餐饮/交通/人情往来/学习/购物/娱乐/医疗/居住/其他）、对方、日期、账户。
- **导入账单**：支持支付宝 / 微信导出的 CSV 账单文件（自动识别编码），导入后进入待确认流程。
- 每笔流水可修改、删除。

## 五、分类（`/categories`）

- 新增活动分类：名称（如「带娃」「冥想」「副业」）、**图标**（图标面板选择）、**颜色**。
- **默认时长（分钟）**：记录时没说时长的日程，按此值记录。
- 可修改、删除分类。

## 六、账户与设置

### 6.0 主题切换（深色 / 浅色 / 跟随系统）

- 导航栏右侧有主题切换按钮（月亮 / 太阳 / 显示器图标），点击循环切换：**深色 → 浅色 → 跟随系统**；鼠标悬停可见当前模式。
- 首次访问跟随系统偏好；手动选择后记住（本机生效），刷新不丢失、无闪白。
- 深浅两套主题共用同一布局与品牌色（sky→indigo 渐变、极光背景、玻璃卡片）；浅色为纯净浅色（白卡片 + 浅灰底）。
- 浏览器地址栏/状态栏颜色（meta theme-color）随主题同步。

### 6.1 首次使用

访问系统时若还没有管理员，会进入初始化页：填手机号、昵称、密码（≥8 位）创建管理员。

### 6.2 登录 / 注册

- **登录**：手机号 + 密码，或 手机号 + 短信验证码（收不到可重发）。
- **注册**：邀请制——需有效邀请码 + 手机号 + 验证码。

### 6.3 个人设置（`/profile`）

- **昵称**：保存后导航栏立即生效。
- **密码**：修改密码（从未设过密码则「当前密码」留空）。

### 6.4 邀请码管理（`/invites`，仅管理员）

- **生成邀请码**：选有效期（7/30/90 天或不限）生成；一码一人，生成后复制发给对方。
- **Token 消耗**：页顶展示自己与被邀请人的 GLM 消耗量——「全部累计」和「近 30 天」两个口径，
  含调用次数、输入/输出 tokens；覆盖识别（parse）、复盘（review）、语音（asr）全部 AI 阶段。
  GLM-5.3-flash 走资源包不计费，语音转写按量计费（约 16 元/百万 tokens）。
- 邀请码列表展示使用状态（未使用/已使用·被邀请人/已过期；未设有效期的显示「不限」）。

## 七、小贴士

1. **想到就说**：不用纠结格式，「今天」「刚」「明天待会儿」这类时间词是 AI 判断日程/待办的关键。
2. **识别错了不用忍**：卡片底部点对应域的图标即可重识别；或直接在卡片上改。
3. **钱先草稿后入账**：动态里说钱不会直接进账本，去财务页确认后才算数，防止 AI 误识别污染账目。
4. **待办不用填时间**：手动新增只写标题即可，完成时会自动按分类默认时长记入今日时间轴。
5. **跨天日程**：晚上 23 点到早上 7 点的睡眠这类跨天块，会同时出现在相邻两天的视图中。
6. 卡路里为 AI 估算值，界面以「≈」标注，仅供参考。
