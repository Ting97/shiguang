# 09 · 账户体系（用户认证）

> 2026-09-17 设计并上线。目标：公网部署的 shiguang.ting97.cn 只允许登录用户访问，数据按用户隔离。
> 背景：此前全站 API 以硬编码单用户 `DEV_USER_ID` 运行，任何访客都可读写数据。

## 1. 登录方式（按落地顺序）

| 方式 | 状态 | 说明 |
|---|---|---|
| 手机号 + 密码 | ✅ 已上线 | 无外部依赖 |
| 手机号 + 短信验证码 | ✅ 已上线（需配置腾讯云 SMS，未配置时提示"通道审核中"） | 密码登录不受影响 |
| 微信扫码 + 绑定手机号 | ⏸ 预留 | 微信开放平台「网站应用」需**企业主体**，个人无法申请；表已预留 `wechat_openid` |
| 注册 | 邀请码制 | 管理员生成邀请码，一码一人；将来开放注册只需加开关 |

## 2. 数据模型（migrations/002-user-auth.sql）

- **profiles** 扩展列：`phone`（唯一）、`phone_verified`、`password_hash`（scrypt）、`wechat_openid`（预留）、`status`、`last_login_at`
- **sessions**：`token_hash`（cookie 只放随机 token，库里存 sha256，可吊销）、`expires_at`（30 天，剩余 <15 天自动滑动续期）
- **sms_codes**：6 位验证码存 hash，5 分钟有效，错 5 次作废，同号 60s/次、日 10 条限流
- **invite_codes**：8 位易读字符（去掉 0/O/1/I），默认 7 天有效，`used_by` 唯一（一码一人）

**存量数据零迁移**：`/setup` 创建的第一个管理员直接继承开发用户 UUID `00000000-…`，既有全部记录自动归属管理员。

## 3. 认证实现（零外部依赖）

- 密码：Node 内置 `crypto.scrypt`（N=16384），格式 `scrypt$N$salt$hash`，`timingSafeEqual` 校验
- 会话：`crypto.randomBytes(32)` → cookie `shiguang_session`（httpOnly/secure/sameSite=lax）
- **middleware.ts 是浅层门卫**（只查 cookie 是否存在，Edge 不连库）；深层校验在各 API 的 `getCurrentUser()`：
  - 页面未登录 → 307 跳 `/login`（跳转地址按 `X-Forwarded-Host/Proto` 还原公网域名，适配 Caddy 反代）
  - API 未登录 → 401 JSON；前端 Nav 挂载时请求 `/api/auth/me`，401 自动回登录页
- 管理员 = 初始化账号（UUID `00000000-…`），仅其可管理邀请码

## 4. API 一览（/api/auth/*，均豁免登录门卫）

| 路由 | 说明 |
|---|---|
| `POST /setup` | 仅当还没有任何绑定手机号的账号时可用；创建管理员 |
| `POST /register` | {phone, password, inviteCode, smsCode?}；SMS 未开通时邀请码即凭证（`phone_verified=false`） |
| `POST /login` | {phone, password} 或 {phone, smsCode}（OTP 登录要求 `phone_verified`） |
| `POST /sms/send` | 限流后调腾讯云 SMS（TC3 签名手工实现，零 SDK） |
| `GET/POST /invites` | 管理员查看/生成邀请码 |
| `GET /me` `POST /logout` | 会话信息 / 退出 |

## 5. 环境变量（.env）

| 变量 | 说明 |
|---|---|
| `AUTH_DISABLED` | **仅本地开发**设 `1` 跳过登录（以开发用户身份运行）；**生产严禁设置** |
| `TENCENT_SMS_SECRET_ID/SECRET_KEY/SDK_APP_ID/SIGN/TEMPLATE_ID` | 腾讯云短信五件套，未配置则验证码通道 503 |

## 6. 腾讯云短信开通步骤（验证码登录启用条件）

1. 控制台开通「国内短信」，个人实名即可
2. 申请**签名**（用已备案网站名，如"拾光"）与**模板**（如"您的验证码为{1}，{2}分钟内有效"）
3. 审核通过后，把五件套写入 `/opt/shiguangri/.env` 并 `systemctl restart shiguangri`
4. 前提：域名已 ICP 备案（ting97.cn 需确认备案状态，未备案则签名审核无法通过）

## 7. 微信扫码（预留，未排期）

个人主体无法申请微信开放平台网站应用（需企业资质 + 认证费）。资质就绪后：接入扫码 OAuth → 拿 openid 匹配 `wechat_openid` → 未绑定则强制走"绑定手机号"流程。表结构已就绪，无需再迁移。
