一、产品介绍

「拾光」是一款面向个人经营的四轴记录系统。核心理念：说一句话，AI 帮你记完一切——发一条动态（文字/语音/照片），AI 自动识别其中的日程、待办、收支、心情、饮食、人物六个维度，确认后自动写入时间轴、待办清单、账本和人际档案。长期积累后，AI 再以日/周/月/年四级复盘把数据变成洞察。

日程块自动落轴，日/周/月/年四视图日历，手动补录缺口，时长统计。

3.2 AI 识别管线（三引擎 + 降级链）

一句话 → Jev 闭集问题组（一次并行 12 问：适用性/活动分类/收支方向分类/餐次/时段/记录类型，校准概率）
       → GLM 瘦身提取（开放词汇：标题/起止时间/人名/饮食条目/心情/金额对方）
       → 合并层（闭集信 Jev·概率作置信；开放字段信 GLM；不一致宁漏勿错）
       → 确定性后处理（时间合法性/区间→时长/ongoing 推导/kcal 求和）
       → v2 zod 契约 校验（不合格自动带错误清单重问一次）

模式开关（管理台「调用引擎模式」，即时生效）：
  off    全 GLM 全量识别
  shadow GLM 行为不变 + 后台同题调 Jev 只写一致率审计（观察期机制）
  on     实时接管（混合引擎 + 空间归属切 Jev）
降级链：Jev 失败/瘦身不合格 → 全量 GLM → 规则引擎（打卡永不失败）；额度熔断 5 分钟防欠费重放

3.3 安全设计

威胁措施
登录暴力破解双层：IP 内存滑动窗口（15min/20 次）+ 身份 DB 锁定（30min/20 次，423）；失败文案统一模糊，不暴露账号存在性；成功即清失败记录
CSRFCookie 会话写请求强制 Origin/Sec-Fetch-Site 同源（middleware 层全覆盖），Bearer 豁免；与 SameSite=Lax 叠加
配置后门APP_ENV=production 时 AUTH_DISABLED 非空 / 弱默认连接串 → 启动即拒绝（fail-fast）
初始化抢占SETUP_TOKEN 一次性令牌（成败都作废，app_config 留痕）
会话盗用全端登出（吊销全部会话）；会话 token 明文不落库（存 sha256）
审计可靠性AI 审计写入失败重试一次 + 结构化错误日志 + 连续失败计数（健康降级信号）
模块越权模块级授权（debt/trade_review）：me.modules 前端可见性 + getModuleUser API 双层门禁

六、设计决策记录（要点）

  • 模块化单体而非微服务：单机部署下收益/成本最优；跨域只走 service 面，为未来拆分留缝。
  • 不引 ORM：手写参数化 SQL 是既有安全资产，仅以 repo 层收口。
  • CSRF 用 Origin/Sec-Fetch-Site 硬校验而非 token：现代浏览器全覆盖，免改全部写路由与前端。
  • AI 双引擎：Jev 概率校准的闭集判断（快 ~6×）+ GLM 开放词汇生成，各取所长；三模式开关一键切换/回退。
  • AI 传输层双通道：Vercel AI SDK（默认）+ 自研 fetch（legacy 回退开关），PoC 实测对照后切换。
  • 迁移 runner + checksum：终结手工 psql，防手改已上线迁移；幂等可回滚。
  • 复盘缓存+配额+数据新鲜度：同一周期秒回缓存；数据更新自动失效；时间解锁预留份额防「刚过 0 点就烧光」。
