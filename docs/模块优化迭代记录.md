### 2026-09-19 · 第 24 轮 · 深色/浅色主题切换（用户指令，原「亮色模式」待办落地）

**需求**：调研主题切换方案，实现深色浅色主题切换。

**方案调研结论**：全站 33 个 tsx 共 1108 处硬编码颜色类，但 Top 20 类占 65%、可归纳为 ~25 个 distinct 类 → 19 个语义令牌；项目零主题基建（无 @theme/无 dark:/无持久化）无历史包袱；Tailwind v4 `@theme inline` + color-mix 原生支持变量透明度修饰符。**自建三态切换（不引 next-themes）**：语义 CSS 变量 + `[data-theme]` 覆写 + 防闪烁内联脚本，深色令牌值与旧硬编码逐一相同（零回归）。

**实现**：
- **globals.css**：`:root`（深色默认）+ `[data-theme="light"]`（纯净浅色：白卡片 #ffffff、浅灰底 #f1f5f9、品牌色加深保证对比）双套 ~40 个变量（表面/文字/边框/玻璃/极光/热力图五档/图表轨道）；`@theme inline` 映射为 19 个 Tailwind 令牌（ink/ink-soft/…、surface/elevated/soft/strong/scrim/wash、line-strong/line/line-soft、accent/danger/success/warn/ai、bg）；组件类（.glass/.btn-*/.msg-banner/.skeleton/.empty-state/滚动条/selection）全部 var() 化；color-scheme 跟随主题（原生控件/滚动条自适应）
- **基建**：layout.tsx `<head>` 内联防闪烁脚本（localStorage → 跟随系统 → 首帧前设 data-theme + meta theme-color）+ suppressHydrationWarning；components/theme-toggle.tsx（Sun/Moon/Monitor 三态循环 + 系统偏好变化实时重解析 + meta 同步）；nav.tsx 右侧挂切换按钮
- **批量替换**：一次性脚本 824 处 / 33 文件（映射含 /透明度修饰符保留）；残留仅 1 处 border-slate-500（待办圆圈，中灰双色可读，有意保留）
- **图表**：year-view 热力图五档色 → var(--heat-0..4)（浅色为浅灰→青渐进）；day-donut 环形轨道、contact-graph 轨道圈 → 图表轨道令牌；moment-feed 日期吸头 → from-bg/via-bg/95；30+ 处 DB 数据色（活动/分类/关系/品牌）双色可读保留不动

**验证**：tsc/build/单测 48/48 通过；构建产物确认令牌工具类 + color-mix 生成；浏览器双主题走查（1280px + 375px）：深色与线上现状一致零回归，浅色首页/日历年视图热力图/人际图谱/财务/登录全部达标（analyze_image 视觉核验 + 计算样式对比度抽查 #475569≈6.6:1 AA）；三态循环/刷新持久化/防闪烁/系统跟随/meta 同步逐一验证。图谱连线透明度（0.12~0.55）为互动密度数据编码，双色语义一致非主题问题。
