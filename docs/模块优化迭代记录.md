# 模块优化迭代记录

> 定时任务（每小时第 25 分钟）驱动：每轮选**一个**模块做完整测试（交互/UI/体验/功能），分级提出问题并优化，验证后记录在本文件；开发计划推进与发布情况一并记录。下轮从下一个模块继续。

## 轮换顺序

动态 → 日历 → 人际 → 财务 → 分类 → 个人设置/登录注册 → 邀请码（管理员）→ 回到动态

## 问题分级口径

- **P0** 功能错误：流程走不通、数据错误、崩溃
- **P1** 体验问题：交互别扭、反馈缺失、易误解
- **P2** 视觉与细节：布局、配色、文案、空态

| 级别 | 问题 | 根因 | 处理 |

| P1 | **跨天块在日视图不可见**（昨晚23:00→今早07:00的睡眠块缺失，凌晨显示"未记录"却会在补录时报冲突） | `calendar/page.tsx` 对 range API（已按交集返回）的结果再用 `start_at` 当地日期过滤，跨天块被筛掉。首页同问题上一轮已修，日历页漏改 | ✅ 移除过滤直接用交集结果；已回归：睡眠块显示 00:00–07:00、缺口从 07:00 起算、环形图含睡眠 |

### 2026-09-18 · 第 1 轮 · 模块：动态

**测试方式**：本地 dev + 浏览器黑盒（桌面 1280px / 移动 375px）+ API 直测；造 25 条跨天种子数据；真实走 GLM 发布多句验证五域链路。

**发现的问题**：

| 级别 | 问题 | 根因 | 处理 |
|---|---|---|---|
| P0 | 识别为**日程块/待办**的动态，发布后 toast 显示「解析失败」、输入框不清空、列表不刷新 | `POST /api/parse` 最终响应漏带 `block`/`todo` 对象（五域改造回归），前端 `j.block.title` 抛 TypeError | ✅ 响应补 `block`/`todo` 字段；前端 `?.` 兜底。已回归：block 分支响应完整、toast 正常 |
| P0 | 「花了268元」被记成**收入**（所有支出全记 in） | 旧约定「amountCents 负=支出」但 prompt 从未让模型输出负数；落库 `<0 ? out : in` 判定错误；金标集无 direction 断言所以没抓到 | ✅ 全链路改为显式 `direction`：schema（FinanceDraft/LlmExtraction）、prompt（direction 定义+正反例）、规则引擎（收入词推断，默认 out）、三处落库（parse×2/recognize/confirm）、金额恒为正；金标加 direction 断言 + 收入用例（42/42），单测 30/30 |
| P2 | 375px 下五域状态条右侧「点图标重识别该域」提示文字挤压竖排 | 固定显示 | ✅ `hidden sm:inline`，小屏隐藏 |
| P2 | 「上周五下午…」类相对日期被时间引擎解析为今天下午（可能撞冲突） | periodHint 无具体日期语义 | ⏸ 记录待办：相对日期解析增强（需扩展 periodHint 或让模型给日期偏移） |
| P2 | 规则引擎 title 偶发破碎（「三点醒了 失眠躺了」） | makeTitle 剥离时间词后残留 | ⏸ LLM 路径 title 质量尚可，规则引擎仅兜底，暂不处理 |

**验证结论**：修复项逐一回归通过；金标 42/42、单测 30/30；发布→toast→列表刷新→冲突提示链路正常；待办新增/完成/恢复、日程补录冲突提示、搜索空态、分页均正常。
