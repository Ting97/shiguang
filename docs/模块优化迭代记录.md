### 2026-09-19 · 第 16 轮 · 语音识别格式修复（用户真机反馈）

**问题**（用户真机报错）：`GLM-ASR HTTP 400: 1214 transcriptions不支持当前文件格式`——MediaRecorder 在 Chrome 产出 **webm/opus**，智谱 GLM-ASR 不收该格式。

**修复**：
- `VoiceButton` 录音后不再直接上传 webm——用 Web Audio API 解码 → 线性重采样 16kHz 单声道 → 手写编码 **PCM16 WAV**（全 ASR 平台支持）上传
- 默认 ASR 模型改为新一代 `glm-asr-2512`（GLM_ASR_MODEL 环境变量可覆盖旧值 glm-asr）

**验证**：
- 直调智谱确认 wav 已过格式校验层（不再报 1214）；当前两个 ASR 模型均返回 429「余额不足或无可用资源包」——**实际转写需在智谱控制台购买 GLM-ASR 资源包**，购买后语音功能即刻可用
- 端到端转写质量用 Windows TTS 生成的中文语音验证（资源包到位后）
