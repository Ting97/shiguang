## Phase 0 · 脚手架 + 语音 PoC（1 周）

| 任务 | 验收 |
|---|---|
| Monorepo（Turborepo：apps/web + apps/mobile + packages/*）、CI、Supabase 本地 Docker | 脚手架可跑 |
| 数据库 Schema v1（时间模块相关表先行）+ Auth | 可登录 |
| **语音/文字多域解析 PoC**：20 句真实话术 → ASR → GLM 解析 → 结构化 JSON | **准确率 ≥85% 才进 Phase 1** |
| 部署演练：Docker Compose 上你的服务器 | 域名可访问（HTTPS） |

## Phase 1 · 时间日记模块（5 周，详见 06 篇任务拆解）

| 周 | 交付 | 验收 |
|---|---|---|
| W1 | Web+App 输入流：按住说话/文字输入 → 解析 → 确认卡片（一键确认/修正） | 打卡→确认 ≤5 秒 |
| W2 | AI 回填引擎（显式时长/相对时间/类别默认时长）+ 8 分类自动归类 | 测试集准确率 ≥85% |

| W4 | **周视图**（7 列缩略+各类合计）+ **月视图**（月历格缩略） | 周/月一目了然 |
| W5 | **年视图**（GitHub 风热力图）+ 每日结构环形图 + Expo App 联调 + **金额联动 v0**（含金额语句 → 财务流水草稿表） | 你连续 7 天真实使用 |
