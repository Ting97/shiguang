## 3. 功能模块全量拆解

### 3.1 智能笔记（AI 日记）—— 核心输入
- 记录形态：**文字 / 图片 / 语音 / AI 对话** 四种，刻意做成"发动态"级别的低门槛。
- 一条笔记发布后，AI **同步自动完成**：
  1. 情绪识别（打标签、情绪值）
  2. 待办提取（自动生成 todo）
  3. 关键动作提炼（关联到目标的关键动作）
  4. 饮食热量识别（拍照识餐、卡路里记录）
  5. 记忆沉淀（写入长期记忆库）
  6. AI 回应（人设化、有温度的评论式反馈）
- 支持双链笔记、数据导出。

### 3.2 AI 目标空间 —— 目标管理闭环
- 完整链路：**创建目标 → AI 分析拆解关键行动 → 推荐伙伴角色 → 日常记录自动触发进展追踪**。
- 目标空间内含：记录、留言、关键动作三要素。
- 进展展示：待办完成情况、能量数据、关键动作执行情况。
- 待办支持日历提醒。

### 3.3 八维生命平衡轮（魔力之花）—— 核心观测模型
- 八个维度：**自我实现、个人成长、人际关系、休闲娱乐、财务状况、职业发展、（家庭/环境）、身心健康**（不同入口口径略有差异，官网为：自我实现/个人成长/人际关系/休闲娱乐/财务状况/职业发展/家庭生活/身心健康）。
- 每条记录按内容归属维度并打分，聚合为花瓣长度，"花瓣随记录与行动生长"。
- 洞察报告展示各维度分数（示例：个人成长 82、身心健康 68、职业发展 76）。

### 3.4 周期洞察复盘
- AI 生成：**日总结、周总结、月洞察、周信**。
- 特色输出：**电台播报**（语音化播报）、**今日之歌**（为当天生成一首歌）。
- 提示状态变化、出现规律、下一步关注点；"发现方向"功能从过往记录中发现成长线索。

### 3.5 AI 智囊团（多 Agent 体系）—— 产品的 AI 架构外显
| Agent | 分工 |
|---|---|
| 远远 | 目标 |
| 记记 | 笔记 |
| 小提 | 待办 |
| 小衡 | 健康 |
| 小餐 | 饮食 |
| 晓悟 | 复盘 |
| 镜镜 | 自我认知 |
| 知知 | 使用指导 |

配套：**角色市场**（可下载他人分享的 AI 伙伴人设）、AI 伙伴可自定义**性格 / 语气 / 关系 / 回应方式**，预设三类：
- 温柔监督型（目标坚持与情绪支持）
- 理性教练型（拆解目标与复盘）
- 朋友陪伴型（日常记录与聊天）

### 3.6 空间与社交
- **私密空间**：主题化空间，可独自记录，也可**邀请信任的人见证变化**。
- **聊天空间**：可拉朋友进空间互动（AI + 真人混合社交）。
- AI 好友互动消息（主动推送、拟人化触达）。

### 3.7 工具与趣味性杂项
情绪追踪曲线、卡路里识别、记账、待办日历、数据可视化、空间精灵桌宠、语音笔记、今日之歌、电台播报、数据导出。

## 4. Web 端技术栈分析（mooly.geetiondata.com）

通过页面 HTML 与资源指纹确认：

| 层 | 技术 | 证据 |

## 6. 用户反馈（App Store 评论摘要）

- 好评：AI 评论互动有启发性；聊天空间私密有趣；"在 AI 伙伴监督下真的瘦了 10 斤"（目标监督场景成立）。
- 差评：AI 对话计算/推理能力弱（模型成本控制的副作用）；部分系统版本闪退（小团队工程质量波动）。
- **启示**：AI 体验质量 = 产品生命线；工程稳定性同样影响留存；模型分级策略（便宜模型做提取、强模型做陪伴对话）是成本与体验的平衡关键。

## 7. 对我方建设的启示

1. **输入端必须极简**：记录的门槛决定数据量，数据量决定 AI 价值。支持一句话 + 图片，AI 负责结构化。
2. **AI 管线是重资产**：一条记录触发 6 种 AI 处理，需要精心设计批处理、缓存与模型分级，否则订阅收入覆盖不了推理成本。
3. **观测模型是差异化核心**：八维平衡轮让散乱记录变成"可观测的人生仪表盘"，这是它区别于普通日记 App 的关键。
4. **情感黏性靠人设**：AI 回应不是客服腔，而是可定制人格的伙伴，配合主动消息形成"被陪伴感"。
5. **社交做轻**：见证人/聊天空间是轻社交，不做重社交关系链，避免冷启动负担。
6. **多端同账号**：Web + App 数据实时同步是刚需（随时随地记录）。
