# 10 · 人际模块（Phase 3 W9 落地记录 + 后续规划）

> 2026-09-18 W9 完成 + W10 核心完成。目标：动态里提到的人自动成档，点开 TA 即见一起经历过的事与关联人情账。

## 1. 已上线能力（2026-09-18）

### 数据模型（零新表，迁移 006 仅加一列）
- `contacts`：name/alias/group_tag/birthday/**anniversary（006 新增）**/intimacy/notes，`(user_id, name)` 唯一
- `interactions`：往来事件，`contact_id` 级联删除；`entry_id`（来源动态）、`tx_id`（关联流水）
- 语音链路早已自动落库：`/api/parse` 抽取 people[] → 联系人 upsert + 往来事件

### 自动建档智能化（apps/web/src/lib/social.ts，纯函数+单测）
- **分组推断** `inferGroupFromName`：同事小李→同事、客户张总→客户、老妈/三姨/岳父→家人，未命中→朋友
- **往来类型推断** `inferInteractionType`：吃饭/喝咖啡/逛街→见面、打电话→通话、收到红包→收礼、帮忙/帮我→帮忙、请客→请客
- **生日倒计时** `birthdayCountdown/birthdayLabel`：今天→"🎂 今天生日"、N 天后生日（注意：pg date 必须在 SQL 里 `to_char` 成 YYYY-MM-DD 再返回，否则 node-pg 序列化成 UTC ISO 会差一天）

### 页面
- **/contacts 列表**：分组筛选 chips（带计数）+ 搜索（姓名/备注名/备注）；卡片=分组头像+名字+生日倒计时+互动次数+最近往来+人情往来净额；＋建档弹层
- **/contacts/[id] TA 档案页**：档案头卡（生日/纪念日/往来次数/人情账收送合计）+ 亲密度进度条 + 备注；**一起经历过的事**时间线（类型图标/日期/摘要/来源动态原文/关联流水金额）；**关联人情账**（流水中对方=TA 且分类=人情往来，含净额）；＋补一笔往来弹窗（不涉及金额，金额走财务"记一笔"并填对方）
- Nav 新增「人际」入口

### API
| 路由 | 说明 |
|---|---|
| `GET /api/contacts` | 列表（含互动次数/最近往来/人情往来净额，按最近往来排序） |
| `POST /api/contacts` | 建档（重名返回友好错误） |
| `GET /api/contacts/:id` | 档案+时间线+关联人情账 |
| `PATCH /api/contacts/:id` | 编辑（分组白名单、亲密度 0~100 校验） |
| `DELETE /api/contacts/:id` | 删除（往来级联，动态/流水不受影响） |
| `POST /api/contacts/:id/interactions` | 手动补一笔往来 |

## 3. W11 星型关系图谱（2026-09-18 开发计划 + 落地记录）

**目标**：/contacts 页提供「列表 | 图谱」双视图；图谱以「我」为中心，一圈联系人按分组着色聚拢，节点大小=亲密度+互动频率，点节点进 TA 档案页（原 W12 交互项并入本期）。

**技术决策（变更记录）**：原计划用 AntV G6，实现时改为**手写 SVG**，理由：
1. 个人联系人规模（几十量级）用环形布局即可，无需力导向引擎；
2. G6 v5 会引入数百 KB 依赖，仅服务一个页面，与项目零图表依赖现状（day-donut/year-view 均手写 SVG）冲突；
3. 布局抽成纯函数（lib/graph.ts）可进单测，G6 渲染不可单测。

**实现拆解**：
| 步骤 | 内容 | DoD |
|---|---|---|
| 1 | `lib/graph.ts` 纯函数：`buildStarGraph(contacts)` → 中心节点 + 按分组排序后均匀布点的圆环（同组相邻、组间空隙）、节点半径=亲密度/互动次数映射、边透明度=互动次数归一化、分组图例数据 | 单测：确定性/半径映射/角度分布/空数据边界 |
| 2 | /contacts 页「📋 列表 | 🕸 图谱」切换；图谱视图 SVG 渲染 + 分组图例 + hover 提示（亲密度/次数/净额/最近往来） | 视觉走查桌面+移动端 |
| 3 | 点节点 → `/contacts/[id]`；中心节点不可点 | 浏览器点击验证 |

**数据**：复用 `GET /api/contacts`（id/name/group_tag/intimacy/interaction_count/gift_net_cents/last_at/last_summary），零后端改动。
