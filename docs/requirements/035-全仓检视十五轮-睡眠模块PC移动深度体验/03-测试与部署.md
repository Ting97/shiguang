**实测通过项**：

- 记录卡：最近一条（日期/小时/感受/得分）+ 近 7 天均值计算正确（实测 6.6 与 API 数据核算一致）；空态引导文案完整；「+ 记录/改今天」随当日是否已记录切换

- 趋势图：睡眠趋势折线 10/01→10/22 首尾标注（6.4h/最新值）、副标题「教练参考它执行『睡眠<6h 降级』协议」完整；PC 与移动 390 均完整可读
- 移动端：全页无横向溢出（scrollWidth==clientWidth）；弹层为全宽底栏形态（390px）；感受三键一行排布；记录入口带 tap-lg 扩展命中区
