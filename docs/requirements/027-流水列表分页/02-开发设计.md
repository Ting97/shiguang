# 027 · 流水列表分页 · 开发设计

## 后端（api/transactions/route.ts GET）

- 新增 `limit`/`offset` query 参数（非法/负值归零，limit ≤ 500）：`limit > 0` 时 SQL 追加 `limit $4 offset $5`（参数化），并行跑 `count(*)::int` 得 `total`；响应 `{ transactions, total }`。
- `limit` 缺省/0 = 全量且**不带** total（响应形状向后兼容，旧调用方无感）。
- where 子句抽公共串，列表与计数两查询共用（draftCond / 北京月 to_char 条件一致）。

## 前端（finance/page.tsx + tx-confirmed-list.tsx）

- 取数从「一条 status=all 拆两段」改为三路并行：overview / `status=draft`（不限量）/ `status=confirmed&limit=visible`。
- `visible` 状态（初始 20）：`load` 依赖 `[month, visible]`，「加载更多」= `setVisible(v + 20)` 触发扩窗重取（替换式，量级小不复用追加）；`gotoMonth` 先重置 visible 再切月；确认/删除等变更操作沿用 `load()` 重取，保持已扩窗口不缩。
- `ConfirmedTxSection` 新 props：`total` + `onLoadMore`；`hasMore = txs.length < total`；标题计数 `20 / N 笔`（加载完回落 `N 笔`）；底部全宽「加载更多 · 还有 N 笔」按钮（ghost 样式，与切月按钮同 hover 口径）。

## 测试（routes-smoke.test.ts 正常层新用例）

- 造 25 条历史月流水：`limit=20` → 20 条 + total 25；`offset=20` → 余 5 条；无 limit → 25 条全量且无 total 字段；用后即清。
