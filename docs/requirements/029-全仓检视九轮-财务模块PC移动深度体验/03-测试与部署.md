**移动 web 390×844**：同链路 + 触控验证（归档按钮 `@media (hover:none)` 恒显可达——hover 才可见的疑虑实测**排除**）；数字输入框原生 spinner 占位在移动端视觉突兀 → 发现与桌面端不一致的细节（见下表）。

**发现并修复**：

| 级别 | 问题 | 修复 |
| --- | --- | --- |
| P1 | **分类占比恒 0%**：`finance/overview` 路由把 bigint 列 `cents` 原样（字符串）塞进 `byCat`，前端 `Object.values().reduce((s,v)=>s+v,0)` 变字符串拼接 → 分母爆炸，所有占比趋 0 | 服务端 `Number(r.cents)` 收口（budget 同口径 `Number()`） |
| P2 | **记一笔表单无账户字段**：语音/CSV 导入均挂账户，手动记的流水 `account_id` 恒 NULL、列表无账户徽标，口径割裂 | `TxForm` 增可选 `accounts` 属性 + 账户下拉（默认第一个账户，可「不挂账户」）；财务页弹层传入 `ov.accounts`；编辑态回显 `initial.account_id` |
| P3 | 数字输入原生 spinner 与设计风格不符（PC hover 才现、移动常驻） | `globals.css` 统一隐藏 webkit/moz spinner |
| P3 | 账户管理期初余额输入框改值后不重置校验状态（同值重输无反馈） | 输入框按 `id:期初` key 重挂 + title 注明口径「改后账户余额=新期初+流水」 |
