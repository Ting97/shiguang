# 019 · 分域助手与体验增强 · 需求设计

> 状态：开发中 · 2026-10-14 · 前置：015（AI 对话助手）/ 016（健身模块）/ 018（运动空间集成）

## 背景与目标

三个域一批：

1. **训练模块**：修复「无安排」导入 500；腰围展示换算 bug；补身高/体脂率记录与趋势；策略档案降低填写门槛（AI 提示 + 一键优化）。
2. **空间域**：以「阶段目标」取代 todo/行动完成率作为空间进度口径（历史列表形态，可多阶段并行）；感悟编辑器补 Markdown 快捷键与工具栏。
3. **助手域**：全局拾光助手之外，各域主页配域助手（目标/日程/人际/财务），运动空间配「运动教练」助手；全局助手可查全系统，域助手只管辖本模块（查询 + 操作）。

## 需求清单

### FR-A 训练模块

| # | 需求 | 验收 |
| --- | --- | --- |
| FR-A1 | 课表导入支持「休息日」语义：用户粘贴「无安排/休息/没有训练」不再 500 | 规则短路 ≤30 字命中 → 400 文案「识别为休息日…」；模型判 rest 分支同样返回该文案；不再出现「服务器内部错误」 |
| FR-A2 | 腰围展示修正 | 录入 88cm 后「最近」行显示 88cm（现状 8.8cm） |
| FR-A3 | 身体指标补身高、体脂率：录入 + 展示 + 趋势图 | 弹窗 4 输入（体重/腰围/身高/体脂）；趋势页体重/腰围/身高/体脂四图；存量旧数据（列 null）不画点 |
| FR-A4 | 策略档案：已知键中文说明（静态指导）+「✨ AI 一键优化」（拉画像/近 90 天数据生成建议 strategy，预览回填不直接落库） | 弹层可见说明；点优化 → 返回 summary + strategy JSON 回填 textarea，用户确认后仍走现有保存 |

### FR-B 空间域

| # | 需求 | 验收 |
| --- | --- | --- |
| FR-B1 | 阶段目标：每空间可建多个并行进行中阶段（标题+可选目标日期），可标记达成/放弃，保留全部历史；空间头部以阶段目标区取代「todo 完成率/行动完成率」两卡；列表页卡片显示阶段摘要 | CRUD + 越权 404；多 active 允许；头部/列表口径切换无残留 |
| FR-B2 | 感悟编辑器 Markdown 工具栏（B/I/链接/H2/列表/引用）+ Ctrl/Cmd+B/I/K 快捷键（选区包裹/无选区插占位） | 预览与列表渲染不变（MarkdownView 复用） |

### FR-C 助手域（分域助手）

| # | 需求 | 验收 |
| --- | --- | --- |
| FR-C1 | 会话与消息带 scope（global/goal/time/people/finance/fitness），域主页只见本域会话 | scope 白名单校验；列表过滤；存量会话默认 global |
| FR-C2 | 工具按域标注并按 scope 过滤：global=全部 24 个；域 scope=本域工具 + get_user_profile | 非 global 会话的 agent 拿不到他域工具 |
| FR-C3 | 五个域人设（目标管家/日程管家/人际管家/财务管家/运动教练），纳管热更（新 PromptKey）；运动教练承接原全局 prompt 中健身教练段 | 各域提问只答本域内容，越域引导回全局助手 |
| FR-C4 | 入口：四域主页 + 运动空间悬浮球+抽屉（复用 AssistantDock 参数化）；移动端整页 /assistant?scope=xxx；首页保持全局助手 | 各域 dock 展开即域助手；对话/历史分页/确认卡不回退 |

## 决策记录

- 阶段目标形态：**历史列表，可多并行**（用户选定）——新表 space_milestones，非单行加列。
- 助手入口形态：**悬浮球+抽屉**（用户选定）——AssistantDock 参数化。
- 配额全局共享不分 scope；提案卡仍仅 fitness（其他域后续按需扩）。
- miniapp 不同步（已暂停）。

## 非目标

域助手独立配额；非 fitness 域提案卡；阶段目标与 todo 自动联动；流式输出；多模板 kind 扩展 UI。
