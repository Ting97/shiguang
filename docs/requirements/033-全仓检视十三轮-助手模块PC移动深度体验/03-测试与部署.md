### P2（11 项全修）

- **activities/[id] 文本主键误校验**：路由用 assertUuidParam，但预设分类 id 是 'sleep' 等文本 → 所有预设分类 PATCH/DELETE 400 → 新增 `assertTextIdParam`（≤64 字非空）双轨
- **transactions 列表排序并列翻转**：`order by occurred_at desc` 无 tie-breaker → 补 `created_at desc, id desc`
- **identity 登录漏 status 校验**：byIdentity 不查 status，停用账号可登录 → 登录链路补检查（模糊失败不泄露账号状态）；查询补 status 列
- **updateProfile 非事务**：改资料与吊销其他会话两步可半完成 → pool.connect 事务化（begin/commit/rollback，内联吊销）；删除死代码 revokeOtherSessions 导出
- **今日日程跨天块编辑误判**（home/today-schedule）：同 calendar-panel 十二轮修复的同源问题——`end <= start` 校验不区分跨天块、保存把结束时间拼回开始日 → `bjDateKey` 判跨天跳过同日校验 + `combineHmEndCrossDay` 保原始日期
- **时间解析·混合上下午**：「上午10到下午2」结束钟点被开始端的 period 污染 → parseClockRange 每端独立 detectPeriod
- **时间解析·「之后/以后」后缀**：relativeOffsetDays 与显式日期正则均不识别「3天之后」「周五以后」 → 两处正则补 `\s*(?:之|以)?后`
- **日期解析·月初/底/末**：「上个月底」无日期 → deterministicOccurredDate 补 `(?:上|本)个?月(初|底|末)` 分支（初=1号、底/末=月末、未来→null）
- **日期解析·显式年份未来日期**：「2026年1月5日」类候选晚于北京时间时误取 → `cand > bj` 直接 return null
- **人名占位词入库**：「某人」「朋友」类泛称被当真实联系人建档 → notPlaceholderName refine 应用到 OpenVocabExtraction.people.name 与 PersonDraftV2.name 并导出复用
- **分转元浮点展示**：`String(cents / 100)` 在部分分值下出长小数（如 3100→31.000000000000004 类） → shared 新增 `centsToYuanInput`（商业整数运算），替换 finance/forms、debt/forms×3、finance/display、recognition-transactions×2 共 8 处

另有 web 组件 P2 同批：publish-sheet 图片移除把 `URL.revokeObjectURL` 写在 setState updater 内（StrictMode 下重复 revoke）→ 移到 updater 外；debt/import-drawer 处理中（busy）Esc/遮罩/× 仍可关闭中断导入 → busyRef 镜像 + guardClose，文件输入补 `e.target.value = ""`；toast z-[100] 被 lightbox 遮挡 → z-[110]。
