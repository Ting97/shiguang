# 026 · 财务收支柱状图 · 开发设计

## 组件（display.tsx / display-overview.tsx）

- `MoneyBars({ trend, direction })`（display.tsx 内部）：单列收/支小柱图，`pick` 取 outCents/inCents，柱高按自身区间最大值线性缩放（`max(6, v/max*56)`，0 值 4px 占位）；悬停 title 显示该月精确金额；当月柱 `ring-1 ring-sky-400/60`（与 SavingsTrend 同标识）。
- `InOutTrend({ trend })`：两列容器 `grid gap-4 sm:grid-cols-2`，各列 TagChip 标题（支出 rose + TrendingDown / 收入 emerald + TrendingUp）。在 `OverviewCard` 中置于 `<SavingsTrend />` 之后，同一玻璃卡内。
- `compactWan(cents)`：金额紧凑口径（≥1亿 → x.x亿；≥1万 → x.x万；否则取整元），仅用于轴标签；精确值走悬停 title（`yuan()` 全额）。

## 视觉口径

- 支出柱：`from-rose-600/50 to-rose-400/80` 渐变；收入柱：emerald 同构——与 TxRow 收/支徽章、三统计卡配色一致（红支绿收全站统一）。
- 空月：标签「—」ink-faint + bg-elevated 矮柱，与储蓄率图 null 口径一致。
