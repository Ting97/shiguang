## 一、动态流模块深度体验（GUI 实测）

本地 3100 standalone（AUTH_DISABLED=1，Docker 测试库 shiguangri_test，迁移 0~064）+ 真实 GLM（glm-4-flash）；种子 `scripts/qa/seed-feed-gui.mjs`（新增，14 条多样化动态走真实五域识别 + 1 条图片 + 1 条语音，`--wipe` 幂等清理）；PC 1440×900 与移动 390×844 浏览器黑盒实测（Playwright 原生 value setter 注入 + CUA 真实鼠标悬停）。

**PC web 实测通过项**：发布（秒回 + 「AI 识别中」占位 → 识别完成 ¥22 落库/心情「困」）；待确认链路（确认 → schedule pending→applied 日程 12:00–13:00 落库；忽略 → 登记簿行消失）；行内编辑（金额/分类回显正确、保存持久化）；两步删除（财务行 + 饮食行，arm→3s 确认→服务端删除）；分页（加载更多 10→14 条、到底提示）；搜索（原文关键词命中 1 条、空结果文案）；空间筛选（运动 → 2 条）；日期跳转（昨天回看 + 回到最新）；语音播放器渲染（0:00/0:04）；图片灯箱（打开/Esc 关/点遮罩关）；亮色/深色双主题；行操作悬停显示（group/row + row-actions CSS 链完整）。

**移动 390×844 实测通过项**：底部 FAB（点按打字/长按说话 56×56）→ 发布面板 → 发布成功；加载更多；灯箱；顶部导航 390px 无溢出（测量验证）。

**观察（记录不修/留专项）**：

- **glm-4-flash 批量 badOutput 率高**：14 条种子并发识别中 6 条（43%）两次校验不过降级规则引擎（错误集中「时刻须为可解析的 YYYY-MM-DDTHH:MM」「todo: Required」「mood.label 非空时 score 必填」）；降级卡片有「离线识别」徽标与重识别入口（产品面完整），但**规则兜底对「门票120」「来回路费40」类显式金额零捕获**（金额被拼进日程块标题），「带儿子去动物园玩了一 门票120 [fe」类截断标题质量差。建议：规则引擎金额捕获扩展 + PoC 句集扩充，单独立项。
- 1×1 极小图片被 object-cover 放大成巨块（真实照片无碍，不修）。
- 「刚喝了杯美式」被规则救回转 schedule pending 50%（激进而有登记簿兜底，符合设计）。
