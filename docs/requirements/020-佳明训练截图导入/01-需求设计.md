# 020 · 佳明训练截图导入 · 需求设计

> 状态：已完成开发 · 2026-10-16 · 前置：016（健身模块，REQ-016 粘贴导入）

## 背景与目标

健身「今日」页的课表导入目前只支持粘贴文本。佳明 Connect 的训练详情以截图传播最广（跑步课「乳酸阈值」、力量循环课「全身循环3」等），用户从 App 里复制文字成本高。本批给训练导入新增**图片识别**：上传佳明训练详情截图，AI（视觉模型）解析成与文本导入同款的结构化计划草稿，复用现有预览确认入库链路。

## 需求清单

| # | 需求 | 验收 |
| --- | --- | --- |
| FR-A1 | 导入卡新增「📷 佳明截图识别」：选择/拍摄截图（客户端压缩）后可与文字备注一起解析，截图可单独识别 | 图片或文本任一即可点「AI 解析」；截图缩略图可预览/移除 |
| FR-A2 | 视觉解析输出与文本解析同契约（FitnessPlanDraftV2 → 整数口径 content），走同一条「草稿预览 → 确认入库 → 联动今日行动」链路 | 跑步截图 → run 草稿（分段+心率目标）；力量截图 → strength 草稿（动作×组×时长，自重） |
| FR-A3 | 佳明截图字段保真：时间驱动步骤（「10:00」）落分段时长；强度目标 bpm 区间（「134-161」）原文保存，**禁止折算 1-5 心率区**（用户分区未知）；力量「N 组」= 循环轮数落 sets、「0:40 · 体重」= 40 秒自重（weightG=0）；「休息」步骤与「按计圈键」提示忽略；概述「总时长」落课时长 | 预览卡与计划卡可见：热身 10 分钟（目标心率 134-161 bpm）；臀桥 3×40s |
| FR-A4 | 截图入参守卫：MIME 白名单（jpeg/png/webp/gif）、base64 合法性、解码后 ≤6MB；纯文本行为不回退（休息日短路等原语义不变） | 非法入参 400 文案；文本导入零回退 |

## 决策记录

1. **视觉模型独立配置**（GLM_VISION_MODEL，默认 glm-4.5v）：主对话模型 glm-5.3-flash 不保证多模态；限流降级不切 glm-4-flash（文本模型不收图，切了必失败）。
2. **客户端压缩复用动态图压缩**（`lib/image.ts` compressImage：长边 ≤1920 / JPEG 0.85）：佳明截图文字密集，该参数保 OCR 可读；常规压缩后 <1MB，走 JSON base64 免新增 multipart 端点。
3. **bpm 区间新增 `hrBpmText` 字段而非复用 `hrZone`**：文本课表的「3 区」才落 hrZone；截图只有 bpm 绝对值，模型折算区间必错。
4. **力量课时长新增 `durationMin`**（草稿 + content + 展示）：佳明力量截图概述自带总时长，落结构化字段优于塞 note。
