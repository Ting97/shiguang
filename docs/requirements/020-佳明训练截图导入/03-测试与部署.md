## 三、部署

1. **新 env**：可选 `GLM_VISION_MODEL`（默认 glm-4.5v，已在 .env.example 与 config.ts 登记；不配即用默认）。
2. 无 DB 迁移（计划 content 为 JSONB，新字段可选、旧数据零影响）。
3. 双 tar 发版后冒烟：健身「今日」→ 导入课表 →「📷 佳明截图识别」上传佳明截图 → 解析草稿 → 保存联动今日行动；回归纯文本导入与休息日语义。
4. 成本关注：一次截图解析 ≈ 1~2 次视觉模型调用（glm-4.5v 计价见智谱定价页）；审计 ai_audit_records `fitness_parse` stage 可查 `model` 分布。
