# 020 · 佳明训练截图导入 · 开发设计

## 链路总览

```
ImportCard（选图 → compressImage → base64）
  → POST /api/fitness/plans/parse { text?, image?{mimeType,base64} }
  → fitnessService.parsePlanDraft(userId, text, image?)
      ├ 入参守卫 validateParseImage（MIME/charset/≤6MB 解码粗检）
      ├ getPromptBundle("fitness_plan_parse")（同 key，system prompt 扩佳明截图规则）
      ├ chat({ images }) → GLM_VISION_MODEL（默认 glm-4.5v，多模态 image_url）
      ├ extractJson → FitnessPlanDraftV2（+一次修复重问，重问同图重发）
      └ draftToCanonicalPlan → content（整数口径）→ attachExerciseIds（力量挂动作库）
  → 前端草稿预览 Modal（复用）→ POST /api/fitness/plans 确认入库（不变）
```

## 分层改动

### packages/ai（纯包）

- `glm.ts`：`ChatOptions.images?: ChatImage[]`（{mimeType, base64}）。带图时 `chatModelOf` 切 `GLM_VISION_MODEL`（`GLM_DEFAULT_VISION_MODEL="glm-4.5v"`，新导出 `activeVisionModel()` 供审计）；legacy 传输 user content 转多模态数组（`image_url.data:` URL）；SDK 传输 `generateText` 改传 `messages`（AI SDK image part 传 data URL，openai-compatible 层自动映射）；**带图调用跳过文本兜底模型降级**。`ChatImage` 类型导出。
- `schema.ts`：`RunSegmentDraft` 增 `durationMin`（0.5~300 分钟，时间驱动步骤）与 `hrBpmText`（≤20 字 bpm 区间原文）；`StrengthPlanDraft` 增 `durationMin`（5~600 分钟总时长）。均可空，向后兼容。
- `prompt.ts`：`FITNESS_PLAN_PARSE_PROMPT` 增「佳明截图识别」段（截图结构/跑步时间驱动课/力量循环课映射规则、bpm 禁折算、休息步骤忽略）+ 两个截图金标准示例（乳酸阈值 tempo 课、全身循环3 力量课）；`buildFitnessParseUserPrompt(text, hasImage)` 支持无文字附图形态。

### apps/api

- `server/platform/config.ts`：注册 `glmVisionModel`（红线 #1，新 env 必须同步）。
- `server/fitness/service.ts`：
  - `RunPlanContentSchema` 分段增 `durationMin/hrBpmText`；`StrengthPlanContentSchema` 增 `durationMin`；`draftToCanonicalPlan` 透传映射（kg→g 等口径不变）。
  - `parsePlanDraft(userId, text, image?)`：`text` 与 `image` 至少一项；休息日短文本短路仅对纯文本生效（附图时文字可能只是补充说明）；带图调用 `maxTokens: 2048 / timeoutMs: 60s`（视觉延迟高于文本）；审计 `model` 记视觉模型。
  - `validateParseImage`：MIME 白名单（jpeg/png/webp/gif）、base64 字符集与最小长度、解码体积粗检 ≤6MB。
- `app/api/fitness/plans/parse/route.ts`：body 增 `image` 可选字段。

### packages/shared

- `fitness-types.ts`：`RunSegment` 增 `durationMin/hrBpmText`；`StrengthPlanContent` 增 `durationMin`（计划 content JSONB 内，无迁移）。

### apps/web

- `lib/image.ts`：导出 `blobToDataUrl`。
- `app/fitness/panel.tsx`：ImportCard 增隐藏 `<input type="file" accept="image/*">` +「📷 佳明截图识别」按钮 + 缩略图预览/移除；解析入参带 `image`；文本与截图任一即可解析。ContentPreview 跑步分段展示 `时长 / 目标心率 bpm`，力量标题旁展示总时长（自重 weightG=0 不展示）。

## 环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `GLM_VISION_MODEL` | `glm-4.5v` | 视觉模型；带图解析与后续图片识别共用 |

## 安全与成本

- 截图仅随请求发给智谱视觉模型（与现有课表文本同通道）；不入库、不落盘（与动态图片上传不同路径）。
- 一次解析 = 1~2 次视觉调用（主调用 + 可能的一次修复重问）；无 DB 写放大。审计沿用 `fitness_parse` stage，`model` 字段区分视觉调用。
