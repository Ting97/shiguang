## 一、交易复盘模块深度体验（GUI 实测）

- **浮层关闭规范补齐**：Modal 新增 `busy` prop（`useDismiss(onClose, !busy)` + × disabled）、reflection-editor 同款；dismissable.tsx 与 toast 等 Esc 路径系统性补 IME `isComposing`/`keyCode===229` 守卫（Enter 路径此前已守，Esc 本轮收口）

- **revoke 在 setState updater 内**（StrictMode 重复 revoke）：publish-sheet ×2、home/use-desktop-publisher ×2 → imagesRef 快照移出 updater

- **AI 金额·中文数字**：「两万」「三千五」「二十五万元」全 null → NUM 字符类扩展 + numOf 约数对（两三万→末位上界）+ 中文尾数；`1.5k` 千倍误读守卫（宁 null 勿错）；tests +6
- **AI 输出·概率口径**：模型回 0~100 概率未归一 → `clampProb`（>1 按 % 折算 + [0,1] clamp）并入 normalize
- **训记同步并发**：syncPlanToXunji 多计划并发时 prev-read/upsert 交错 → 每计划 `pg_try_advisory_lock`（50×100ms 重试，失败 conflict）临界区；updateXunjiSync 失败不再静默（console.error）；sync/pull 路由补 `assertUuidParam`
- **排序确定性**：people/repo ×3、insight/review-ctx ×3（detail 查询补 id select）、finance review/week、admin prompts preview → 补 `, id` tie-breaker
- **admin prompts 写路径事务化**：PUT 与 restore 两步写可半完成 → `pool.connect()` begin/commit/rollback
- **timeline 口径**：`{ direction, yuan: cents / 100 }` 字段名 yuan 装分值 → `{ direction, cents }`；涉及消费方核对无（内部消费同批修正）
