# 025 · 睡眠感受与 App 得分 · 开发设计

## 数据模型（迁移 `062-sleep-feeling-score.sql`，只增不改）

```sql
alter table public.fitness_sleep_logs
  add column if not exists feeling text check (feeling in ('good', 'ok', 'bad')),
  add column if not exists score int check (score between 0 and 100);
```

## 后端（fitness 域）

- repo `upsertSleep` 增参 `feeling?/score?`，on conflict 用 `coalesce(excluded.x, fitness_sleep_logs.x)` 实现部分更新；`listSleep` 查询列补 feeling/score。
- service `SleepInput` zod 增 `feeling: enum(good/ok/bad).nullable().optional()`、`score: int 0-100 nullable().optional()`；`saveSleep` 透传（null 归一）。
- 打卡路径不动：`upsertSleep(..., "checkin")` 不传新字段 → coalesce 保留既有感受/得分。

## 教练/助手（chat/tools.ts query_fitness_logs）

- sleep 序列元素带 `feeling`/`score`（`row.feeling ?? undefined`，缺列旧行自然省略）；unitHint 注明「feeling good/ok/bad，score 为手环 App 睡眠得分 0-100」。

## 前端（panel.tsx SleepCard）

- `SLEEP_FEELING_META`：good=饱满 / ok=一般 / bad=疲惫（emoji + 文案）。
- 录入 Modal：感受三枚快捷按钮（选中高亮）+ 得分数字输入（0–100）；`openModal(forDate)` 从当日已有记录预填三字段。
- 卡面展示：`7.5h · 饱满 · 82分`（感受/得分有值才显示）；近 7 天均值行不变。

## 测试（fitness.test.ts）

- 024 用例扩展：saveSleep 带 feeling=ok/score=82 往返读回；同日只更新 hours 的二写保留 feeling/score（coalesce 语义）。
