# 023 · 训记动作映射确认 · 开发设计

## 数据模型

迁移 `060-xunji-aliases.sql`：

```sql
create table if not exists fitness_xunji_aliases (
  user_id uuid not null references profiles(id) on delete cascade,
  local_name text not null,
  official_name text not null,
  created_at timestamptz not null default now(),
  primary key (user_id, local_name)
);
```

repo 层：`listXunjiAliases(userId)` / `upsertXunjiAliases(userId, entries)`（unnest 批量 upsert，改选覆盖）。

## 名称解析管线（优先级从高到低）

```
用户别名表(060) → XUNJI_NAME_ALIAS(内置实测) → 目录精确命中 → 【同步】needsConfirmation 确认流
                                                              → 【保存】AI 批量匹配(022) → 保留原名
```

- `xunji.splitOfficialNames(names, catalog, userAliases)` 纯函数（同步用）：返回 `{resolved: Map, unmatched[]}`；目录为空时内置别名仍生效、其余全部 unmatched（宁缺勿错，与旧 makeOfficialResolver 同语义）。
- `ruleMatchOfficialNames` 增第三参 userAliases（保存路径 022 编排用），优先级最高。
- `makeOfficialResolver` 退役（service 不再引用；仍导出供旧测试）。
- `planToTrain` 的 officialName 回调允许返回 null——null 表示用户确认跳过，该动作不进 movements。

## 同步确认流（service.syncPlanToXunji）

签名扩为 `(userId, planId, fetcher?, confirm?: { mappings?, skips? })`：

1. 加载目录快照（022 分层缓存）+ 用户别名表。
2. 力量分支：动作名（排除 skips）过 `splitOfficialNames` → `unmatched` 非空且**非确认调用** → 返回 `{needsConfirmation: true, unmatched: [{name, candidates}]}`（HTTP 200；candidates = prefilterCandidates top-8 带 type）。
3. **确认调用**（mappings/skips 至少一项）：校验 mapping 的官方名 ∈ 目录快照（防拼错）→ 批量 upsert 别名表 → 并入 resolved；`skips` 只影响本次载荷（resolver 返回 null），不删计划动作。
4. 确认后回写计划内容：`renameExercisesToOfficial`（佳易名备注）直接走 repo.updatePlan（绕过「仅草稿可编辑」——同步确认的改名要与训记载荷一致）。
5. 全部动作被跳过/无法解析 → 400「没有可写入训记的动作」；目录不可得且有目录外名 → 退回旧拦截文案（无候选可确认）。

保存路径（savePlanDraft 带 syncXunji）：内部同步返回 needsConfirmation 时不算失败——`xunjiWarning` 提示「请在计划卡点同步训记完成确认」。

## API

`POST /api/fitness/plans/[id]/sync-xunji`：无 body = 首次同步（可返回 needsConfirmation）；`{mappings, skips}` = 确认调用。响应新增 `skipped: string[]`。

## 前端（panel.tsx PlanCard）

- `syncXunji(confirm?)`：响应带 `needsConfirmation` → 存 `xunjiConfirm` 弹 Modal（每动作 select：候选官方名带分类 / `__skip__`）；默认选第一个候选，无候选只能跳过。
- 「确认并同步训记」→ 组装 `{mappings, skips}` 重发 → 成功 toast 带「跳过 N 项」。
- 修复顺手带入：同步按钮 `onClick={syncXunji}` 会把点击事件误传为 confirm 参数 → 改 `() => syncXunji()`。
