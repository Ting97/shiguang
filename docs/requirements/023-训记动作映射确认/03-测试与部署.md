## 二、踩坑记录

1. **Bash 后台化吞 export**：`export X=… && nohup ssh … & disown` 的 `&` 会把整条 `&&` 链后台化，主 shell 拿不到变量——隧道/环境变量一律先写脚本再 `source`，脚本内变量记得 `export`（非 export 变量子进程读不到）。
2. **repo.updatePlan 约定**：vals 末两位必须是 `[id, userId]`（SQL 里 `$n-1/$n` 反向取参），直调时容易漏。
3. **onClick 传参陷阱**：`onClick={syncXunji}` 会把 MouseEvent 当首个参数传入——带可选参数的处理函数必须 `() => fn()`。
