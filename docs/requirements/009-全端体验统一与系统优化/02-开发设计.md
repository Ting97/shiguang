
### 1.3 生成与校验

- `generate.mjs`：读取 tokens.ts → 渲染四份产物，头部写 `/* GENERATED BY @shiguangri/design-tokens — DO NOT EDIT（手改会被 CI 拒绝）*/`。
- `verify` 模式：重新渲染与磁盘 diff，不一致 exit 1。接入 root `package.json` scripts：`"tokens": "node packages/design-tokens/scripts/generate.mjs"`, `"tokens:verify": "… --verify"`；CI 中 `npm run tokens:verify`。
- **接入方式（关键约束）**：web `globals.css` 与 miniapp `app.scss` 不整文件生成——只把**变量段**（web :root/[data-theme=light] 的变量声明区、miniapp page{}/.theme-light 对应区）替换为 `/* TOKENS:BEGIN */…/* TOKENS:END */` 标记块，生成器只重写块内内容；块外的组件级 CSS（.glass/.btn-* 等）保持手写。

### 1.4 mobile 接入与漂移修复

- `apps/mobile/App.tsx` 删除 THEMES 常量与死常量 `C`，改 `import { THEMES } from "@shiguangri/design-tokens/generated/mobile-themes"`（数值回漂归零：glassBorder 0.16→0.12、glassHighlight 0.06→0.04、scrim/aurora 系列对齐）。
- miniapp：`app.json` 加 `"darkmode": true`；`theme.json` 生成（navigationBarBackgroundColor 等映射双主题）；`app.scss` 骨架屏 `.skeleton` 渐变改 `var(--skeleton-1/2)`（修复浅色不翻转 bug）。
- miniapp README 铁律 1 改写：`src/app.scss` 的 TOKENS 块与 `src/lib/theme.ts` 的主题机制文件解冻为"生成物/机制文件，改动须走 design-tokens 包"；页面局部样式仍冻结。
