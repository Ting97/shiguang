## 同批第二批：深度体验优化（2026-09-24）

「记录 → AI 识别 → 确认 → 日程」主链路 GUI 深度体验（PC 1440×900 + 移动端 390×844，本地真实链路），记录-识别-确认-冲突-补录-todo 全部验证可用，第一批修复项线上行为确认（冲突 409 北京时间、规则降级、单域识别、延迟刷新）。本批优化：

1. **AI confidence 容错**（packages/ai schema）：GLM 偶发输出非数字 confidence（如 "medium"）导致整包 zod 校验失败 → 白白丢弃合法字段并触发规则降级（实测复现）。改为 `llmConfidence = z.coerce.number().min(0).max(1).catch(0.5)`：垃圾值回落 0.5（低于 0.6 阈值 → 转待确认），语义仍为「不掩盖不确定」
2. **日程冲突提示就地处理入口**：动态流冲突横幅新增「去调整 →」链接，跳 `/schedule?date=<记录日>`（新增 date 参数锚定 + CalendarPanel initialAnchor）
3. **calendar-panel load 请求竞态守卫**（体验验证中发现的真实 bug）：锚定切换/快速翻日时旧区间响应后到会覆盖新数据（实测 23 日锚定显示空数据）——补 seq 序号守卫，仅最新请求落地
4. **块删除两步确认**：BlockEditor 删除按钮改「删除 → 确认删除？」（3s 防误触窗口），calendar-panel 移除原生 window.confirm（与全站样式化确认一致）
5. **今日行动空态去重**：移除与头部「规划 →」重复的空态 CTA；添加框 placeholder 缩短（修复移动端截断为「自动标记今E…」）
