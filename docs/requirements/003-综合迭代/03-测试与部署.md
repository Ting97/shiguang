## 统计一致率查询（shadow 期间每周跑）

```sql
select date_trunc('week', created_at) as wk,
       count(*) as total,
       count(*) filter (where ok) as consistent,
       round(100.0 * count(*) filter (where ok) / count(*), 1) as一致率,
       count(*) filter (where not ok and error like '%schedule%' or error like '%activity%') as sched域差异
from audit_logs where stage = 'jev_shadow' group by 1 order by 1 desc;
```
