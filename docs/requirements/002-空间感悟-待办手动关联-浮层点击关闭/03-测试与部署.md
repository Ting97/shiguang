## 批次 2-0：空间加载卡死修复（500e632）

- **根因**：①主因——部署双 tar 换血后，已打开的旧会话按旧 chunk 清单懒加载路由 → 404 → `loading.tsx` 永久兜底；②次因——`spaces/[id]/detail.tsx` 的 `load()` 无 try/catch，fetch 抛错即永远"加载中"（contacts 孪生页有处理，spaces 漏网）。

- **验证**：注入 chunk 失败事件 → 守卫标记落位 + 自动 reload ✓；断开 API → 错误态+重试按钮渲染 ✓（shots/2026-09-22-08-detail-err.png）。
- 部署后冒烟：active / login 200。
