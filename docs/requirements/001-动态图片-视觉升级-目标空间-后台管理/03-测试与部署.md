### 批次 2 测试摘要（本地 + 生产）
- API 断言：保存覆盖 → GET overridden:true；版本快照留存；restore 回滚；enabled=false 停用；空内容 400、未知 key 404；DELETE 恢复默认。
- AI 优化真实调用（glm-4-flash，~15s）：建议稿含三键契约；弱模型回显输入块问题已在服务端启发式剥离（lastIndexOf「【当前 prompt】」）+ 元 prompt 强化；audit_logs 记 `prompt_optimize` 阶段。
- 浏览器（PC 1280）：/admin 双 tab、16 key 清单（分类分组/覆盖徽标/渐变激活）、编辑→未保存徽标→保存→DB 覆盖徽标、AI 建议并排对比→采纳/放弃、营销管理（用户套餐/邀请管理/Token 统计）。
- /profile：管理员区块无残留、后台入口卡显示；/invites → /admin 跳转。
- 生产：普通用户「用户6944」访问 /admin 显示 403 态（截图）；未登录 /api/admin/prompts 401；nginx 未登录页面 307 门禁不变。
- 教训记录：① 本地 3100 standalone 服务未停时重建 API 会因 `.next/standalone` 被锁而卡死——重建前先 kill 服务；② 重建 API 后 `standalone/apps/api/out` 被清，本地测试前必须重新拷贝（与部署红线同理）。
