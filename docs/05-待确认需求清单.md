## 2. 财务模块 —— ✅ 已确认（2026-09-16）

| # | 结论 |
|---|---|
| F1 账单来源 | **支付宝/微信 CSV 导入 + 语音 + 手动**；**核心联动：在时间模块记一笔时，AI 自动识别是否涉及金额，有则自动录入财务流水**（一句话多域落库） |
| F2 专业程度 | **普通用户视角**（收支/分类/账户：现金/支付宝/微信/银行卡）；复式记账不做，投资账户后期待定 |
| F3 预算 | **月度总上限预警 + 分类统计报表**（不做信封预算，保持轻量） |
| F4 复盘重点 | **月度结构占比（同比环比）+ 储蓄率趋势**；人情往来专项账由人际模块联动自然呈现 |

## 3. 时间日记模块 —— ✅ 已确认（2026-09-16，优先级 P0 最先开发）

| # | 结论 |
|---|---|
| T1 输入入口 | **手机 App 为主力**，同时支持**文字输入**（语音/文字双通道，同一套 AI 解析管线）；智能手表后期评估 |
| T2 时间块起止 | **AI 回填推断**："刚跑完步40分钟"→结束于当下、回溯40分钟；"下午跟客户聊了2小时"→自动定位到下午时段 |
| T3 被动追踪 | **不做**（不用 ActivityWatch 式屏幕监控，纯主动记录） |
| T4 活动分类 | **预设 8 类 + 可自定义**：睡眠/工作/学习/健身/社交/娱乐/家务/通勤，AI 自动归类 |
| T5 日历视图 | **内置四级日历**（应用内自足）：**日视图**（24 小时完整时间轴，每个时间段落位）／**周视图**（列式缩略一览）／**月视图**（传统月历格）／**年视图**（全年概览）；ICS 导出订阅为可选增强，CalDAV 双向同步二期评估 |
| T6 复盘重点 | **A+B+D**：每日时间结构、周/月趋势曲线、年度热力图（GitHub 风格）。（浪费预警 C 暂不做） |

## 4. 人际模块 —— ✅ 已确认（2026-09-16）

| # | 结论 |
|---|---|
| P1 数据来源 | **边用边加 + 手动建档并用**：语音/文字提到某人→自动创建联系人；重要的人手动完善档案 |
| P2 人情粒度 | **事件级+金额**：送礼/收礼/请客/帮忙各记一笔（含金额），自动联动财务"人情往来"分类 |
| P3 图谱形态 | 一期做**"我为中心"星型图**（分组环绕、节点大小=亲密度/互动频率）；联系人互联完整图谱后评估 |
| P4 提醒 | **生日/纪念日提醒**（"没联系提醒""礼尚往来欠账提醒"暂不做） |
| P5 隐私 | **常规云端加密存储起步 + 预留本地部署版本**（端侧加密暂不做） |
| P6 AI 能力 | **交往风格总结为核心体验**：与 TA 有交集时，点开即见——**一起经历过的事情（时间线）+ TA 的爱好/喜好/忌讳提炼**（见面前的"复习卡"）；淡出预警、代写问候语暂不做 |
