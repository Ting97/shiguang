1 · 总览

定位个人经营系统——把钱 · 时间 · 人三大资产纳入同一套仪表盘，一句话（语音/文字）同时落三本账，AI 交叉复盘
业务五域一条输入可同时命中：时间块（日程/待办）+ 收支（流水草稿）+ 人物（联系人/往来）+ 心情（mood）+ 饮食（卡路里，北京自然日口径）
关键数字3端客户端 · 10 页面 · 30+ API 路由 · 21 张表（20 个迁移）· 21 个组件 · 48+ 单测 · 单服务器（腾讯云 2C4G）
形态云端多端账号制（邀请码注册），Web 为主力，Expo 原生 App 提供语音记账与登录保持，WebView 壳作快捷入口

3 · 接入层与安全体系

Caddy（443/80）HTTPS 自动签发续期；按 Host 分流：shiguang→:3000，trade/tend 互不影响
双层门卫① middleware.ts 浅查 cookie 存在性（Edge，不连库）→ 页面 307 跳 /login（按 X-Forwarded-Host 还原公网域名）② 各 API 内 getCurrentUser() 深校验会话 → 401 JSON
会话cookie 存随机 token（32B），库存 sha256 可吊销；30 天有效期，剩 <15 天滑动续期；登出/改密即失效

5 · 核心业务流

5.1 记录发布全链路（产品的灵魂）

  • 输入：Web 文字 / Expo 长按录音（voice-recorder → ASR 转写，隐私模式音频不落盘）
  • 解析：POST /api/parse → GLM 抽取（AI 为主，意图判定 recordType past/future）→ zod 校验（失败规则引擎兜底+日志）→ 确定性时间推断（秒清零整分对齐）
  • 落库（单事务）：entries → future? todos（due/remind=提前15min，不再生成日程块）: time_blocks（先 tstzrange 重叠检测，409 中文提示）→ finance.hasAmount? transactions(draft) → people[]? contacts upsert + interactions（分组/类型推断）→ mood/diet 识别 → entry_recognitions 留痕（009 analyzed_at）
  • 呈现：动态流卡片秒存 + 五域识别产物异步上卡；时间轴/待办区实时刷新

5.2 待办生命周期

  • future 话术/手动 → pending（due_at + remind_at）→ 勾选 done（解耦：不产生日程）⇄ undone 恢复 pending → 也可编辑/删除
  • 提醒：GET /api/reminders 聚合 remind_at 已到期 + 生日/纪念日 7 天窗 → 工作台横幅（当天可关闭）

5.3 CSV 导入（两段式）

  • 上传/粘贴 → 平台自动识别（支付宝/微信）→ GBK 自动回退解析 → 预览列表（映射分类、商家→对方、红包转账→人情往来）→ 确认入库
  • 去重双保险：external_no 单号唯一索引（005）+ 内容指纹 → 重复导入 0 新增

5.4 复盘生成（AI + 缓存 + 配额）

  • 日/周/月/年复盘：SQL 先聚合事实（LLM 不编数字）→ GLM 解读 → review_caches 缓存；新鲜度 latest 取"≤now 的最近块"（012：未来计划块不参与，修 P1）→ 新动态即失效
  • 配额防滥用：review_gen_quotas（018）限制生成频率；token 全量入 audit_logs（011）

6 · AI 引擎详解（packages/ai）

组件细节
模型与接入GLM（OpenAI 兼容 v4），当前 glm-4-flash（账号可用资源包）；glm.ts：30s 超时、markdown 围栏剥取、错误透传；Web 端经根 .env 软链接读取
输出契约（zod）recordType(past/future) · activity(9 类) · title(≤8 字概括) · durationMin(null 不猜) · periodHint(7 时段) · finance{hasAmount,amountCents(分),category,counterparty} · people[{name,event}] · ambiguity(追问)
时间推断（确定性，模型不编时间戳）① explicit："刚…40分钟"→end=now 回溯 ② relative："下午…两小时"→锚点(14:00)+时长 ③ default：类别默认时长 ④ future→TODO：明天/后天/下周X（周一定位）/待会儿(now+1h)/钟点（中文"三点"+下午=15:00）；全部秒清零；过去语境锚点在未来→视为昨天
意图判定AI 判定为主（016），规则词表兜底（明天/下周/待会/打算…；"一会儿"分语境：过一会儿=未来，刚做了一会儿=过去）
可靠性校验失败→规则引擎兜底（confidence 0.5）+ 服务端日志；占位人名过滤（"省略/无"）；错例进回归测试与金标集
已知观察项（金标集迭代）"下午三点开会一小时"歧义（钟点 vs 时长）；LLM 时间抽取边界持续回归
