## 发布流程（增量更新）——2026-09-20 起三端架构版

> 架构：`apps/web` 纯静态导出（out/）由 `apps/api`（API + 静态托管 catch-all）同域服务，单元 WorkingDirectory 已指向 `/opt/shiguangri/apps/api`（旧配置备份在 shiguangri.service.bak）。

```bash
# 1. 本地构建（web 静态导出 + api standalone）
npm run build            # = build:web + build:api

# 2. 同步产物（standalone 整树 + 静态 out）
tar czf - -C apps/api/.next/standalone . | ssh tencent "rm -rf /opt/shiguangri_new && mkdir /opt/shiguangri_new && tar xzf - -C /opt/shiguangri_new/"
tar czf - -C apps/web out | ssh tencent "tar xzf - -C /opt/shiguangri_new/apps/api/"
ssh tencent "cp /opt/shiguangri/.env /opt/shiguangri_new/.env"

# 3. 切换 + 重启（保留旧版秒级回滚）
ssh tencent "systemctl stop shiguangri && rm -rf /opt/shiguangri_old && mv /opt/shiguangri /opt/shiguangri_old && mv /opt/shiguangri_new /opt/shiguangri && systemctl start shiguangri"
```

> **旧版（单 apps/web standalone）回滚**：`ssh tencent "cp /etc/systemd/system/shiguangri.service.bak /etc/systemd/system/shiguangri.service && systemctl daemon-reload"` 后按上法换回旧目录结构。

> **Windows 终端无 rsync 时的等价做法**（2026-09-17 实测）：tar 管道 + 目录切换，保留旧版本可秒级回滚：
> ```bash
> cd apps/web
> tar czf - -C .next/standalone . | ssh tencent "rm -rf /opt/shiguangri_new && mkdir /opt/shiguangri_new && tar xzf - -C /opt/shiguangri_new && cp /opt/shiguangri/.env /opt/shiguangri_new/.env && mkdir -p /opt/shiguangri_new/apps/web/.next"
> tar czf - -C .next static | ssh tencent "tar xzf - -C /opt/shiguangri_new/apps/web/.next/"

> # 验证无误后可删 /opt/shiguangri_old；出问题则反向 mv 回去即回滚
> ```

## 账户体系（2026-09-17 上线）

- 全站需登录访问：未登录页面 307 → `/login`，API 返回 401；首次部署访问 `/setup` 创建管理员（继承开发用户 UUID，存量数据零迁移）
- 设计详见 [09-账户体系.md](09-账户体系.md)；生产 `.env` **严禁设置 `AUTH_DISABLED`**
- 验证码登录需在服务器 `.env` 配置腾讯云短信五件套（见 09 §6），未配置时密码登录不受影响

## 坑位记录（迁移时注意）

1. **CentOS PG13 默认密码加密是 md5**，pg_hba 改 scram 前必须先 `set password_encryption='scram-sha-256'` 再改密码，否则永远认证失败。
2. `pg_hba.conf` 的 127.0.0.1 行要从 `ident` 改为 `scram-sha-256` 并 reload。
3. monorepo 的 standalone 产物在 `.next/standalone/apps/web/server.js`（镜像目录结构），static 需手动补到 `apps/web/.next/static`。
4. 时区：库按 `Asia/Shanghai` 显式切分日期（API 已内置），服务器系统时区也确认是 CST。
5. 环境变量在服务器 `/opt/shiguangri/.env`（不入库）；本地仓库的 `.env` 仅用于开发。

## 凭据管理约定（2026-09-17 确认）

- **生产凭据唯一来源：服务器 `/opt/shiguangri/.env`**（含数据库密码、智谱 Key、模型名），长期保存在服务器上，其他终端需要时直接取用：
  ```bash
  ssh tencent "cat /opt/shiguangri/.env"
  ```
- 仓库永远不存密码（.env 已 gitignore，.env.example 只留字段名）。
- 新终端接入开发的前提：配好 SSH（`~/.ssh/config` 加 `tencent` 主机 + 对应私钥），即可读取凭据、发布代码、查日志。
- 若泄露需要轮换：改服务器 .env → `systemctl restart shiguangri` → 同步更新本地开发 .env。

## 数据说明

- 本地数据迁移到服务器：本地 `pg_dump --data-only` → 服务器 `psql` 导入（注意用户 id 一致，当前都是开发单用户）。
