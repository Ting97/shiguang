## 一、视觉 UI 感受

- 空间列表空态：「目标把这一年献给什么」大标题 + 场景举例 + CTA，是全站最好的空态设计。
- 新建空间弹层：名称/描述/12 图标/6 色/开始-目标日期分区明确，创建键禁用态正确。
- 空间卡片：图标 tinted 底 + 名称 + 「0 待办 · 0 动态 · 第 N 天」+ 待办进度，信息密度合适。
- 空间详情：头部（图标/标题/开始日期/第 N 天/归档/删除）+ 完成率双统计 + 关联待办（带添加框）+ 相关动态，层次清楚；两处空态文案都带操作指引。
- 日历 tab：日期导航（‹ › 今天）+ 日/周/月/年视图切换 + 当日结构侧栏 + ✨AI 日小结（无记录时按钮禁用并解释，有记录后启用并提示「让 AI 通读当天的时间/待办/收支/人际」）——状态联动细致。
- 分类 tab：9 个预设带默认时长、可改不可删的规则以顶部一句说明交代，新增自定义表单（名称/颜色/默认时长）齐整。

## 三、BUG 清单

- **B1（P2，本轮已修 F5）**：新建空间默认开始日期用 `new Date().toISOString().slice(0,10)` 取 UTC 日期，北京 00:00–08:00 创建会默认成昨天，且「第 N 天」统计从昨天起算（实测：09-22 05:15 打开弹层默认 2026-09-21）。全站 grep 仅此一处误用（spaces/[id]/detail.tsx 的 +8h bjDate 是有意为之，不在列）。
- **B2（P3，本轮已修 F6）**：发布 textarea maxLength=2000 无字数反馈，粘贴超长被静默截断。已在 ≥1800 字时显示 n/2000（≥1950 标红）。桌面端输入区（page.tsx）为另一实现，本轮未加计数器（下轮可顺手对齐）。
