# 体验轮训报告：首页今日 + 时光流动态（2026-09-22 03 轮）

- 轮次：定时轮训第 1 轮（03:10 触发）
- 环境：本地 standalone :3100（AUTH_DISABLED=1），移动 375×812 优先，PC 1280 复核，浅/深双主题
- 产物：修复 2 项（F1 识别超时兜底、F2 今日待办完成即消失），见文末「本轮迭代」

## 一、视觉 UI 感受（移动 375 优先）

**做得好：**
- 顶部导航胶囊 tab（动态/目标/日程/人际/财务）选中态蓝底白字，主题切换按钮常驻右上，层级清楚。
- 今日行动卡片：勾选圈 + 标题 + 橙色「今天」到期 tag + 右上「规划→」，信息密度恰当。
- 动态卡片：左侧时间线圆点 + 图标圆底 + 类型 chip（动态/待办/心情）+ 离线识别警示 chip，扫描性好；心情设置后卡片头图标变 😊、出现「此刻心情：满足」行，正反馈明显。
- 「识别与补充」底部弹层：六类信息行（图标+标题+副标题+铅笔）、点行=AI 识别/铅笔=手动补充的图例说明、心情 chip 十档选择 + 选中高亮 + 行尾打勾，完整顺滑。
- 暗色主题：深蓝底 + 暗灰卡片，对比度整体协调，无发现文字不可读区域；PC 1280 居中单列布局 + 桌面输入区（记录此刻… + 按住说话 · Enter 发布），视觉稳定。
- 时间轴「今日日程」：0-24 点全轴 + 红色当前时刻线（03:14 标注）+ 未记录整段横条，可读性好。

**问题（见 BUG 清单 B2/B3）：**
- 「AI 识别中」紫色 chip + 省略号文案没有时效边界，两天前条目仍在转圈（视觉上像产品坏了）。
- 今日行动卡片全完成后标题行计数消失、正文换成「今天还没有行动」——与刚完成的操作矛盾。

## 二、功能体验（交互路径实测）

| 路径 | 结果 |
| --- | --- |
| 麦克风 FAB 点按 → 发布弹层 → 填文字 → 发布 | ✅ 秒回上墙，绿色 toast「AI 正在识别…」，今天分组出现，离线规则即时提取待办（明天上午九点 → 9月23日 09:00 ✓） |
| 点动态原文 → 识别与补充弹层 | ✅ 六类行完整；点「心情」行触发 AI 识别该类，结果以行内绿条反馈（「未识别出心情，已清除原心情」） |
| 铅笔手动补充 → 心情 chip 选择 → 添加 | ✅ 卡片即时更新（心情 chip + 😊 + 此刻心情行 + 「已设置心情」反馈），弹层行尾打勾 |
| 搜索「复盘」 | ✅ 「找到 1 条」+ × 清除；无结果时空态文案友好（换个关键词，或点 × 清除搜索） |
| 今日行动 ✓ 完成 | ✅ 完成；❌ 完成后条目整个消失（F2，见下） |
| ⋯ 菜单（编辑/删除） | ✅ 触屏常显（hover:none CSS 适配到位），锚定弹出定位正确；深链接见 B4 |
| 主题切换 浅→深 | ✅ 即时生效；按钮图标随模式变化（☀️/🌙/🖥） |
| 空间链路 | 无 active 空间时「所属空间」显示空态文案、feed 空间切换条正确隐藏 ✓ |

已知限制：发布弹层图片上传依赖系统文件选择器，IAB 自动化无法覆盖（真实设备已在此前批次验证）。

## 三、BUG 清单

- **B1（P1，本轮已修 F1）**：AI 识别状态无超时兜底。复现：发布动态时 AI 调用失败/丢失 → `analyzed_at` 永远为空 → 卡片「🤖 AI 识别中 正在提取…」无限转圈。实证：本地 9月20日 14:48/14:50 两条已转圈 2 天（截图 shots/2026-09-22-03-home-light-mid.png）。
- **B2（P2，本轮已修 F2）**：今日到期**顶层待办**完成即从首页清单消失。复现：首页今日行动唯一条目「悬浮圈自测：十点开会…」点 ✓ → 清单变空并显示「今天还没有行动」误导文案；已完成项无处查看、无法恢复（行动级不受影响，因其保留在视图内进「今日已完成」）。
- **B3（P3，未修）**：搜索框 placeholder「🔍 搜索：原文/日程/待办/金额/联系人」在 375 宽下贴边显示，视觉偏挤；建议移动端缩短为「搜索动态…」。
- **B4（P3，未修）**：动态「⋯」菜单定位只有下方 clamp（`window.innerHeight-100`），无顶部/导航栏避让；卡片紧贴吸顶导航半露时菜单可能被盖住。低概率。
- **B5（P2，观察，未修）**：麦克风 FAB 悬浮在 feed 卡片上时会遮挡文字（mid 流转状态），建议 feed 底部预留 FAB 直径的滚动 padding，末条完整可读。

## 四、改进建议（按价值排序）

1. **F1 识别超时兜底（P1）**：feed 查询对 `analyzed_at is null and created_at < now()-'10 minutes'` 输出 `recognize_state='timeout'`，前端显示「🤖 识别未完成 · 点击原文可重新识别」（slate 灰 chip，不再转圈）。只读 CASE，无迁移。
2. **F2 今日待办保留完成态（P2）**：today-actions 顶层待办分支放宽 `status in ('pending','done')`，完成后进「今日已完成（可恢复）」区，计数正确显示 1/1；行动级行为对齐。
3. 搜索 placeholder 移动端缩短（P3，建议下轮顺手）。
4. feed 末条滚动 padding 让出 FAB（P3）。
5. 空日程时 24 点时间轴压缩或折叠，减少两屏空滚动（P3，建议日程模块轮细评）。
